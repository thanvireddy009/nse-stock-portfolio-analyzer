#NSE stock Portfolio analysis(NIFTY 50)
A Python-based portfolio analytics tool that evaluates NSE (NIFTY 50) stocks using returns, allocation, and performance metrics to simulate real-world equity research workflows.

#Why I built this project
The goal of this project was to understand how real-world stock analysis works, including:
- Price trends  
- Risk and return behavior  
- Financial performance metrics  

It also helped me strengthen my skills in Python data analysis and financial modeling.

#Features
- Live NSE stock data analysis (via Yahoo Finance)
- Technical indicators (Moving Averages)
- Risk metrics (Volatility, Returns)
- Financial statement analysis
- Interactive visualizations using Plotly
- NIFTY 50 stock selection dashboard

#Tech Stack
- Python  
- Streamlit  
- Pandas  
- Plotly  
- yFinance

#How to run
1. Clone the repository
2. Install dependencies
   pip install streamlit yfinance pandas plotly
3. Run the app
   streamlit run app.py

#Output
Portfolio dashboard showing:
Stock price trends
Moving averages
Financial ratios
Risk metrics
