#NSE stock Portfolio analysis(NIFTY 50)
Python program for portfolio analysis of stocks based on data from the NSE

#Why I built this app?
My goal was to familiarize myself with how real-life stock portfolios are assessed, namely their returns, risks, and sectors. 
This project simulates a basic portfolio analysis workflow used in equity research and retail investing.

#Features
- Tracks portfolio performance over time  
- Calculates returns for individual stocks  
- Analyzes overall portfolio performance  
- Visualizes data using graphs  
- Helps understand diversification across stocks

#Tech Stack
- Python  
- Pandas  
- Matplotlib  
- NSE data (CSV / APIs)  

#How to run
1. Clone the repository
2. Install required libraries:
   pip install pandas matplotlib
3. Run the Python file:
   python main.py
